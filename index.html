      Computer Systems

      A computer system consists of hardware and software. Hardware includes physical components such as the CPU, monitor, keyboard and mouse. Software includes programs and applications that tell the computer what to do. The operating system manages computer resources and allows users to interact with the computer.

      Reading Comprehension

      5 câu

      Network Systems

      A computer network is a group of computers and devices connected together to share information and resources. Networks can be classified into different types, such as LAN and WAN.

      LAN stands for Local Area Network. It is commonly used in homes, schools and offices. WAN stands for Wide Area Network. It covers a larger geographical area and can connect computers in different cities or countries.

      A router is an important network device. It forwards data between networks. Network security is also important because hackers and malware can damage computer systems. A firewall helps protect networks from unauthorized access.
